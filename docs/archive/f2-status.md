# 已完成阶段归档：F2 status 与单文件 index 操作

本页保存 F2 收尾时的交付结论和未测边界，不追随后续代码更新。有效行为见 [F2 契约](../emacs-fidelity.md#阶段-f2status-与单文件-index-操作)，JS 接口见 [配置文档](../scripting.md)，当前工作及所有未完成事项以[计划](../plan.md)为准。

## 交付结论

F2 已按用户批准的 status / 单文件整文件级 stage / unstage 范围完成。交付包括固定仓库身份与只读 status 投影、折叠 / 刷新 / 多 view / 另存解绑、随包 JS 工作流与默认 `s` / `u`、核心持有的写入及结果记录、过时标识和正常退出协调；支持矩阵、过滤器 / hook 策略、不确定结果与跨 reload 所有权遵循长期契约。

产品实现已分批集中审查并修复发现项，普通及 profiler 回归、Clippy、脚本 / 类型与工具自检均完成；无已知阻塞性遗留项。设计稿中的有效行为、资源边界及 API 已提炼到契约、技术决策和配置文档，实施细节不再作为独立的有效规格维护。

本阶段不是完整 Magit 或通用扩展平台：不包含 hunk / 批量写入、discard、commit、冲突解决、transient、任意 Git / 进程 API、Promise / async 或持久化 Job。后续范围另行确认，不把这些非目标当未完成的 F2 待办。

## 收尾边界

用户确认现有 headless 基线、自动化与单窗口宿主功能证据足以完成当前 F2 范围，不追加原生性能、GPU 或 IME 矩阵。这里的阶段完成不是宣称所有性能预算通过：status / 写入端到端没有新增时延门限，headless 只记基线；不套普通正文 300 ms 或 JS 资源期限，也不把测试调度器合并后的观察当原生逐帧提交。

原生 CPU draw / 滚动 / idle、GPU 执行 / 实际呈现时延与真实 IME 在本阶段未测，不是阻塞性待办。实际宿主窗口尺寸未提供，可读性 / 焦点来自用户观察，未独立诊断默认字体解析。历史字体、中文输入和聚合性能观察仍留在计划，原预算及旧超限结论不变。

Git 操作在后台执行且有资源保护，不代表任意仓库、磁盘或外部锁条件下的固定端到端时延保证；仍不承诺外部并发事务、自动回滚或崩溃后的操作恢复。若日常使用出现实际问题，再按影响确认定向排查，不因阶段结束自动补开宿主矩阵。
