# 已完成阶段归档：F6 文件夹 tree viewer

本页保存 F6 收尾时的交付结论和未测边界，不追随后续代码更新。有效行为以 [F6 契约](../emacs-fidelity.md#阶段-f6文件夹-tree-viewer) 为准；当前工作和重要未完成事项以[计划](../plan.md)为准。

## 交付结论

F6a 项目根、F6b 独立文本树 / 固定左侧 side window、F6c 导航与访问均已按批准范围完成。树复用现有 buffer / view / section、mode 局部键位、统一命令注册和文件打开生命周期；项目根只提供当前根查询，不提前扩展为项目切换或项目内查找。

本地功能 / headless 回归和 F6b / F6c 各一次集中审查后的修复已完成；单窗口宿主功能观察与独立 fixture 核对通过，无已知阻塞性遗留。收尾没有代用户提交工作区，也没有启动下一 project 阶段。

上游参照及静读补充仍见 [treemacs 参照](references/treemacs-reference.md)，它不是 semacs 通过记录。上游目录上的显式 `o` 访问会打开 dired；用户批准 semacs 仅提示暂不支持目录访问，不创建 split，差异已进入有效契约。其余首版排除的上游能力仍以契约为准，不把候选项视为未完成 bug。

## 验证依据与边界

固定源码 / release 二进制身份、宿主环境、三组用户观察、独立 project / 配置路径及字节核对、本地检查与审查摘要，见 [F6 单窗口宿主功能验证](../records/f6-tree-host-01.md)。受测对象是基础 HEAD 加完整 tracked / untracked patch，不是基础 HEAD 单独对应的代码。

宿主只观察侧窗布局 / 宽度、访问目标与焦点、当前文件定位和空闲后的 follow；助手未独立操作或截图复现。用户没有提供窗口尺寸，宽度没有独立的像素 / 列测量，follow 没有量化精确 0.2 秒。根识别、异步失败隔离和完整树状态回归主要依据本地自动测试。

本阶段不新增性能门限；原生 CPU 性能、真实 IME、GPU / 屏幕呈现时延未测，不宣称总体性能预算通过，也不改变历史已接受的性能观察。后续 project / diff range / 缩进等方向需另行确认，不因 F6 收尾自动开始。
