## 交付结论

F3 已按用户确认的临时 window 与无需 semacs 代收密码的普通 commit 范围完成。交付包括局部显示 / 退出恢复、真实 Git editor 会话和消息保存 / 取消 / 恢复、仓库进程输出与控制、非密码提示、终态刷新及正常退出协调。无 staged 时采用 Magit 默认 ask-to-stage 流程，不增加 staged-only 限制，不禁用正常 hooks / 签名来缩减产品流程。

用户已明确将密码 / passphrase 读入排除于 F3，不是未完成的阶段任务；后续需求留在计划。其他未批准的更多 Git 操作、完整 transient、通用 async / Job 或持久化恢复也不随本阶段自动交付。

阶段集中审查一次，四项发现已修复并通过受影响回归和完整本地检查；用户获准的单窗口宿主功能验证及离线字节核对也已通过，无已知阻塞性遗留项。有效行为已提炼到长期契约，工作稿只保留来源与静态核对入口，不另维护实施 / 测试矩阵。

## 收尾边界

宿主只覆盖 Linux x86_64 / Wayland 的一个 OS 窗口及内部分屏，窗口尺寸与可读性来自用户记录；不宣称跨平台或完整视觉矩阵通过。OS 关闭实际覆盖拒绝退出后继续编辑，信号发送、忽略 / 捕获与两级控制的更广生命周期仍依据隔离本地证据，不把它们冒充本批宿主观察。

真实 IME、原生 CPU 性能、GPU / 屏幕呈现和实际签名工具交互未测；密码读入在阶段范围之外。普通 hooks / 签名配置的底层保留有隔离证据，不等于任意用户工具或密码提示均有 GUI 支持。

本阶段完成不表示任意仓库的端到端时延保证、所有性能预算通过、外部并发事务 / 自动回滚或崩溃恢复。原性能预算与已接受的字体、中文输入和聚合性能观察均不变，仍留在计划。只有实际问题或另行确认的新范围才触发后续定向工作，不因归档自动追加宿主矩阵。
