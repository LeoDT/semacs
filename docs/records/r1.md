# R1 验收归档

固定记录 2026-10-31 起的 R1 验收与实测，不作为当前代码能力清单；后续结果另行记录，不回写历史值。
性能指标含义及已批准预算见 [性能预算](../performance.md)。Emacs 外部行为观察单独保留在 [对照基准记录](../../tests/emacs/RESULTS.md)。

## 验收结论

用户已确认 **R1 完成**，采用以下组合证据：

- 真实 Hyprland / Wayland / fcitx5 Pinyin 的输入、候选窗、失焦及关闭功能验证，首轮使用软件渲染。
- 用户在正常宿主终端执行的 RADV 硬件路径普通 / IME CPU 绘制与平台提交流程测量，共 36 次；已核对完整产物，且用户批准独立原生预算。
- headless 只读与最小输入预算已批准，固定环境内的实测满足预算。

GPU 执行时间、实际屏幕呈现、纯实体按键 / IME 回调到屏幕的端到端延迟均未测；用户接受其为 R1 限制，不作为本次阻塞项，不能改记为通过。
D17、失焦与关闭沿用首轮真实 Wayland 软件渲染证据，不要求仅因渲染器切换整套重跑；硬件性能流程没有重跑这三项。
其他输入法、X11、键盘布局、缩放配置及完整 Emacs 命令链未因此获得验收。R1 完成不等于 v1 完成，阶段补测见 [实施计划](../plan.md)。

## 真实 Wayland 输入功能

环境：Hyprland 0.56.2、fcitx5 5.1.23、fcitx5-chinese-addons 5.1.15，Pinyin。
首轮工具无 `/dev/dri`，显式 `LIBGL_ALWAYS_SOFTWARE=1`，GPUI 报告 llvmpipe / is_software_emulated=true，LLVM 23.1.3、Mesa 26.2.5-arch1.1。
使用原生字体、实际合成器和 fcitx5 协议；wtype 经合成器注键，不是伪造 IME 回调，也不替代实体键盘。
测试窗口主要位于非零原点 (1723, 67)，854 × 1370。候选位置由截图观察，不是像素误差或延迟统计。

| 场景 | 结果 / 断言 |
|---|---|
| 原生显示 | 中文、emoji、组合字符、tab、空行、EOF 可显示 |
| 普通输入 / 换行 | 输入 ASCII，Return 新增 LF；观察到准确正文和 point |
| 删除 | Delete 删除正文首字符；Backspace 依次删除 combining acute、e、emoji，UTF-8 未损坏 |
| 普通预编辑 | 输入 ni，仅 display 含 marked；clean 用例的 committed / point / modified 不变 |
| 候选窗 | 截图观察到 fcitx5 候选窗在 caret 附近；非零窗口原点没有错误偏移 |
| 换行 / 软换行 | caret 移到新行、120 个数字形成软换行后，候选窗跟随到对应行 |
| 滚动后组合 | 连续 60 次 Return 触发 caret reveal / 视口滚动，再组合时候选窗仍锚定可见 caret |
| D17 | 组合中 C-x 不修改正文，不启动前缀，echo 显示 composition-active 提示 |
| 取消 / 提交 | Escape 清除 ni，已提交正文不变；再次 ni + Space 提交你，未重复插入 |
| 失焦 / 重聚焦 | hao 预编辑期间切走窗口，再回来无残留预编辑；已有提交保留，随后 Z 正常插入 |
| dirty + 预编辑关闭 | 已有提交且 ni 仍 marked 时发关闭请求；只丢弃 marked，显示 Cancel / Discard，原提交保留，确认前窗口不关闭 |
| 取消确认 | Escape、C-g、默认 Enter 均取消并恢复输入，随后可继续输入；dirty 保持 |
| 明确丢弃 | Tab 选择 Discard 后 Enter，测试窗口关闭，进程正常退出 0 |
| 只有预编辑时关闭 | 没有已提交修改，组合期间关闭直接退出 0，不产生 dirty 确认，不提交临时文字 |
| 清理 | 测试窗口 / 进程已清理；原测试文件 SHA-256 未变，原焦点和 fcitx 活动状态已恢复 |

首轮发现确认框仅可鼠标操作；修复后重验取消、继续输入、安全默认与明确丢弃，上表反映修复后的结果。
独立性能入口的软件自检共普通 18 次、IME 18 次；发现并修复远滚动后改宽 / 字体的空白正文，修复后矩阵无空白帧，样本未变、焦点 / 输入法已恢复。软件自检不是硬件预算证据。

其他关键范围（合并普通与 IME 矩阵中对应阶段）：

- 单次 Window::draw 最大值最高 14.669 ms；这是包含布局 / shaping 的 CPU 侧墙钟耗时。
- 四类自动输入同步更新最高 0.653 ms；32 次同回调输入 / 删除的整批同步更新最高 31.119 ms，首次提交最高 32.384 ms。
- 滚动首次提交 0.627–2.647 ms；稳定强制重绘提交 0.435–0.968 ms。
- 改宽 / 字体后第一份场景提交最高 31.208 ms，可能仍绘制保留快照；
  当前新布局的完整就绪提交最高 218.901 ms，不把旧字体 / 宽度的绘制当作新布局完成。
- 所有非打开更新的完整就绪提交最高 246.553 ms，出现在单条 ASCII 超长行的真实预编辑流程。
  单行局部输入仍可能触发后台剩余整行重排；前台不等待全文。

全部采集数据满足独立原生预算，未观察到前台同步全文重排。冷打开包含新窗口创建和系统初始化，不能推断其全部耗时用于正文排版。

## 证据位置与复现

原始产物在本地 `.pi/tmp/`，不纳入版本控制；本归档保留必要结论与数据摘要，不依赖这些临时文件作为唯一记录。

- `r1-native-hardware/`、`r1-native-ime-hardware/`：用户宿主硬件 CSV、环境、汇总、日志与候选截图。
- `r1-native-report.json` / `r1-native-state.tsv`、`r1-native-clean-report.json` / `r1-native-clean-state.tsv`：完整输入 / 关闭及 clean 取消验证，报告 completed=true。
- `r1-native-perf-retained/`、`r1-native-perf-ime-retained/`：修复后软件性能自检；`r1-final-headless-perf-after-retained.csv`：修复后 headless 回归。

复现入口见 [性能测量入口](../performance.md#测量入口)；原生功能诊断使用 `examples/native_input.rs`，仅接受可丢弃样本，状态日志不是性能计时。
历史桌面测试授权不自动延伸到后续测试；复现真实环境需重新征求同意。
